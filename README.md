# Grab —— 小说整本抓取器

给一个**详情页 URL**，自动完成：抓目录 → 抓正文 → 装配 → 净化 → 验收 → 输出 TXT →（可选）推到手机。

内置便携 Node，**目标电脑不需要安装 Node / npm / 任何依赖**。

---

## 一、快速开始

### 双击

直接双击 `grab.bat`，会打印用法后停住（方便看输出）。

### 命令行

```bat
grab.bat https://www.18xsb.com/book/18810/
grab.bat https://www.18xsb.com/book/18810/ --probe
grab.bat https://www.18xsb.com/book/18810/ --jobs 3 --delay 250
grab.bat https://www.18xsb.com/book/18810/ --push
```

成品在 `out\<书名>.txt`，章节缓存 `books\<书名>\ch\0001.txt`。

### PowerShell 里调用

```powershell
.\grab.bat https://www.18xsb.com/book/18810/
```

不要用 `node -e "..."` 这种内联一行写法（PowerShell 会吃掉引号和 `$`），一律走 `grab.bat` 或写成 `.mjs` 文件。

## 二、参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `<URL>` | 必填 | 书籍**详情页**地址，不是搜索页 |
| `--name` | 自动 | 书名，影响输出文件名 |
| `--limit N` | 0 | 只抓前 N 章，用来试跑 |
| `--jobs N` | 2 | 并发数，建议 2~3，超过 4 容易触发站点限流 |
| `--delay ms` | 400 | 每次请求间隔 |
| `--out dir` | `./out` | 成品目录，相对 `Grab` 根目录 |
| `--books dir` | `./books` | 缓存目录，跨机续跑时指向共享盘 |
| `--push` | 关 | 用 adb 推到 `/sdcard/Download/` |
| `--probe` | 关 | 只探测结构，不抓正文。站点适配第一步就靠它 |

## 三、输出长什么样

```
简介
<og:description，已净化>

第1章 第一章
正文……
```

- 章节标题统一成 `第N章`（顺序编号），站点原编号重复/错乱时也不会撞号。
- 站点原名会保留在章号后面：`第1章 意外来客`。
- 阅读 App 的本地 TXT 目录规则按 `^第N章` 识别，可直接拆章。

验收报告每次都打印：

```
章数 95 | 字数 642184 | 平均 6760
字数区间 2522 ~ 20857
偏短章 无
重名章 无
净化删除 477 行
输出 out\新婚.txt 1.87MB
```

## 四、站点适配流程

**第一步永远是 `--probe`。**

```bat
grab.bat <详情页URL> --probe
```

输出告诉你是哪一环没识别：

| probe 输出 | 改哪里 |
|---|---|
| `目录链接: 0` | `pipe.mjs` 顶部 `HEAD_RE`（目录链接的文本特征） |
| `正文容器: 未识别` | `CONTENT_HINTS` 数组，把该站正文容器的 id/class 加进去 |
| 正文能抓但夹广告 | `AD_LINE` 里补关键词 |
| 书名/简介是空的 | 站点没有 og 元标签，用 `--name` 手动给 |

三个常量都在 `pipe.mjs` 开头 20 行内，改完直接重跑，不用重新打包。

正文容器识别顺序是按 `CONTENT_HINTS` 逐个试，命中后要求文本 > 200 字才算数，避免抓到空壳 div。

## 五、送进阅读 App

### 方式一：WIFI 传书（推荐）

1. 电脑和手机同一 WiFi。
2. 阅读 App 右上角 `⋮` → WIFI 传书，屏幕显示 `http://192.168.x.x:1122`。
3. 电脑浏览器打开该地址，上传 `out\<书名>.txt`。
4. App 里「本地书籍 → 扫描本地文件 → 加入书架」。

### 方式二：adb

```bat
grab.bat <URL> --push
```

推到 `/sdcard/Download/`，再在 App 里扫描。没有 adb 时脚本会打印 WIFI 传书的提示，不会中断。

## 六、断点续跑

- 每章单独落盘 `books\<书名>\ch\0001.txt`，中断后重跑自动跳过已完成的章（文件 > 100 字节即视为完成）。
- 想重抓某章：删掉对应文件再跑。
- 换电脑想接着抓：把 `books\<书名>` 目录一起拷过去，或用 `--books` 指向共享盘。
- 抓坏了想重来：整个删 `books\<书名>`。

## 七、便携运行原理

`grab.bat` 只调用 `%~dp0runtime\node.exe`，不读系统 PATH，所以：

- 目标机没装 Node 也能跑；
- 不污染系统环境变量；
- 换电脑只需整个文件夹拷走。

| 事项 | 说明 |
|---|---|
| 体积 | 约 95MB，其中 `runtime/` 92MB |
| 系统要求 | Windows 10/11 x64；ARM/32 位需换对应 Node 包 |
| 杀软 | 便携 `node.exe` 可能被误报，加白名单 |
| SmartScreen | 首次运行 bat 可能提示“未知发布者”，选仍要运行 |
| 编码 | bat 内已 `chcp 65001`，中文输出不会乱码 |

`runtime/` 不能删。`books/`、`out/` 可以随时删。

### 从仓库克隆后重建运行时

仓库里**不含** `runtime/`（92MB 二进制）。新机器上先跑一次：

```bat
setup-runtime.bat
```

它会用系统自带的 `curl` + `tar` 下载官方 Node v22.23.5 (win-x64) 并解压到 `runtime/`，约 34MB 流量，之后 `grab.bat` 即可用。系统要求 Windows 10 1809 以上（需要 `tar`）。下载失败时手动解压同名 zip 到 `runtime/` 也一样。

## 八、文件清单

| 文件 | 作用 |
|---|---|
| `grab.bat` | 入口，固定调用便携 Node |

| `out/` | 成品 TXT |
| `HISTORY.md` | 开发记录与踩坑清单 |

## 九、常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| `目录链接: 0` | 目录是 JS 渲染，或链接文本不含“第N章” | `--probe` 看 HTML；JS 站需换方案 |
| `正文容器未命中` | 正文 id/class 不在内置名单 | 加进 `CONTENT_HINTS` |
| 状态 403 / 返回登录页 | 站点要求 Cookie 或 UA | 换 UA，或补 Cookie 头 |
| 抓到一半停住 | 站点限流 | 降 `--jobs` 到 1，`--delay` 加到 1500 |
| 单章字数异常大 | 站点把一章切成几十页 | 已限 8 页，超出会让该章偏大 |
| 中文乱码 | 站点 GBK 未识别 | 已内置 `TextDecoder('gbk')`，仍乱码就把响应头贴出来 |
| 简介带广告 | 站点在 meta description 塞广告 | 已过滤；关键词漏了就往 `AD_LINE` 加 |

## 十、边界

- 只支持**静态 HTML** 站点；纯 JS 渲染（接口返回加密 JSON）不在此工具范围内。
- 不做站内搜索，必须给详情页 URL。
- 不输出 EPUB，只出 TXT。
- 抓取频率请自觉控制：2 并发 + 400ms 间隔，是多数站点不触发封禁的下限。
- 仅用于个人已购/公开内容的离线阅读，不要用于再分发。
